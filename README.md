# Mom Appreciation Universe

A static, mobile-friendly Mother's Day sample website that can be uploaded directly to GitHub Pages.

## Files

- `index.html` - page structure and sections
- `style.css` - responsive styling and animations
- `script.js` - star canvas, memory modal, music toggle, and day counter
- `assets/` - sample images and audio placeholder

## Replace Later

In `script.js`:

- Change `birthDate` to your real birth date.
- Replace the `memoryStars` titles, messages, and image paths.

In `index.html`:

- Replace the sample letter.
- Replace the timeline text.
- Replace gallery captions.

In `assets/`:

- Replace the `sample-memory-*.png` files with real photos.
- Replace `soft-note.wav` with a song or voice message you are allowed to upload publicly.

## Open Locally

Double-click `index.html` to preview it in a browser.

## Upload To GitHub Pages

Upload all files and folders to the root of a GitHub repository, then enable GitHub Pages from the repository settings.
